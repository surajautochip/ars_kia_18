Custom Login Background

Make your Odoo login screen unique. This module allows administrators to configure a stunning background image for the login and signup pages on a per-company basis, removing default footers and keeping your branding front and center.

📸 Module Screenshots

Visual walkthrough of the Custom Login Background module

1 Configure the Background Image

Upload a unique high-resolution picture to serve as the background for the authentication pages. We recommend using a 1920x1080px (16:9) image to avoid any stretching or visual artifacts.

Go to Settings → Companies → [Select Company] and upload your image in the Login Background Image field.

Company settings page showing the new background upload field.

2 The Beautiful Login Page

Once uploaded, the background image seamlessly covers the login and signup pages. The module also removes default Odoo branding footers for a fully clean aesthetic.

The beautiful custom login page in action.

Key Features
  • Set a custom background image for the login page and signup page
  • Easily upload the picture within the Company Settings via the browser
  • Supports different background pictures for each company
  • Automatically removes the default Odoo "Powered by Odoo" footer on login pages
  • No complex file overrides — pure backend configuration
  • Improves first impressions of your system
